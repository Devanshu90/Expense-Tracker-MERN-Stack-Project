# Expense Tracker (MERN Stack)

A full-stack Expense Tracker web application built using the MERN stack to help users efficiently manage their personal finances. The application allows users to securely track income and expenses, monitor account balances, and view transaction history through an intuitive and responsive interface.

## Features

- User Authentication (Login & Signup)
- Add, Edit & Delete Transactions
- Income & Expense Tracking
- Dashboard with Financial Summary
- Transaction History
- Responsive UI
- Secure REST APIs

## Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

```bash
git clone https://github.com/Devanshu90/Expense-Tracker-MERN-Stack-Project.git
cd Expense-Tracker-MERN-Stack-Project
npm install
npm run dev
```
